**Libell 1.3** — a second sensor box, set up entirely from Libell. 1.1 brought the first external box; 1.3 adds the Xparkle RVS01, gives every box the same short setup page, and then goes over the whole app with one rule in mind: show the problem and how to fix it, never refuse. Along the way the help was rewritten, screen readers were given something to read, and the code underneath was taken apart into small, tested pieces.

Open it at **https://moggleif.github.io/libell/** — if you already have it installed, it updates itself on the next start, and you can now ask it to check by tapping the name in the top-left corner.

## Highlights

- **The Xparkle RVS01 as a second sensor box.** Connect it from the **Sensor box** page and it reads the tilt instead of the phone, exactly as the EasyLevel box does. You never need the Xparkle app: Libell zeroes the box with its own command, sets which way it faces, and can learn its mounting by watching you raise the front and then the right side. The box must stand upright, and its page says so whenever it is lying down. If the box rejects its password, the page says **Wrong password** and lets you type the box's four-digit code instead of failing with a vague "could not connect". Tested on a real box on Android.
- **One page per box, two steps.** The sensor box page used to be three stacked sections of paragraphs and buttons. Every box now gets the same page: a header that says the state in a few words ("Connected · battery 62 %", "Lost contact") with the one button that fixes it, a live line that shows how the box stands and how it tilts, and a checklist of just two steps — **Direction**, then **Zero on level ground**. For the Xparkle box you pick the direction by tapping the side of your own vehicle the box points to; for the EasyLevel box you pick one of the manual's two placements. **Disconnect** greys the steps out rather than hiding them, so you can still see what is set.
- **EasyLevel caught up.** Everything the Xparkle box got — silent reconnect, the lift guide, the two-step page, the help — works for the EasyLevel box too.
- **A steadier screen with a box.** A box reports a few times a second, and the wheel heights and the bubble used to jump at each reading. Box readings are now smoothed, so the screen glides from one reading to the next.
- **Warnings instead of refusals.** Calibrating the phone or zeroing the vehicle more than 15° off level used to be refused. Now Libell explains why it looks wrong and offers **Calibrate anyway** / **Zero anyway**. The same goes for box zeroing and saved targets, the feedback form (it warns about an empty title instead of disabling the button that sends it), and a step height that cannot be used (it says why instead of greying out **Add**).
- **New Settings and Help.** Settings opens on tabs that wrap to a second row on narrow phones instead of being cut off. Help is a set of short fold-out topics, each with a button straight to the place it talks about, and every topic was rewritten this week: what the screen shows and what a step is, what the measurements and ramps are for, what calibrating and zeroing each mean and how to tell the vehicle is level, which boxes there are and how each is mounted, and the exact messages you see when something is wrong.
- **One word per step.** _Calibrate_ now means only the phone's own sensor on a flat surface; _Zero the vehicle_ means setting the vehicle's level. The two used to be mixed up across the app, settings, help and the guide, in all five languages.

## Smaller things you may notice

- **Check for a new version** by tapping the Libell name and version in the top bar. One launch is now enough to pick up a new deployment.
- The caravan has its own drawing in Modern, and every wheel shows one height: how much to lift it. A grey wheel with no ramp now shows its lift too, so you know how high a board would need to be.
- The warning lamps are more honest: **⚠ Setup** stays lit until you have actually entered the measurements, and with the phone in use the amber lamp asks first for **Calibrate**, then for **Zero**.
- The introduction has one path for zeroing, a note on each step that names the real lamp and button, and **Skip** only where there is a form to skip. Skipping the measurements no longer forgets which vehicle you picked.
- The "no new sensor data" and "sensor tilted too far" screens now have a button straight to the **Sensor box** page.
- A browser without Web Bluetooth now gets a **Sensor box** page too, saying which browsers can connect a box.
- Sound works from the first tap after launch; before, the chime and audio guidance stayed silent until you touched a setting.
- Chrome 153 on Android no longer gets the iPhone's **Start** button.
- **Copy debug info** includes the temperature and uses the same labels as the screen.
- Measurements from storage or from a shared setup link that are far outside any plausible range fall back to the default instead of producing nonsense; the fields say what range they accept.

## Accessibility

- Each wheel tells a screen reader what it needs, the page announces when you reach level or the data goes stale, and focus stays inside an open page or dialog.
- The page carries its language, so a screen reader uses the right voice, and lists say which item is selected.
- Contrast is higher for the no-ramp wheel, form fields and the calibration pills.

## Under the hood

- Nothing about the leveling math or your stored settings changed in a way you need to act on: settings from 1.2 carry over.
- `main.ts` now only connects the app's modules, and every function and file is held to a size limit by CI. Every refactor was done in small steps with tests written first that pin the behaviour before and after.
- New guards in CI: function and file size, unused exports, file paths named in the docs must exist, and a test-coverage floor.
- The fit check now covers all three appearances, Glossy included, and runs one appearance per parallel job.
- 1995 unit tests, up from 651 at 1.2.

## Honest limitations

- The Xparkle box has been tested on one real box on Android. Which edge the box treats as its front is still assumed for the direction buttons; the lift guide measures it instead, so use that if the wheels come out wrong.
- Unchanged from 1.2: the EasyLevel support is built against the box's decompiled protocol and exercised with a simulator — **no physical EasyLevel box has ever been connected to this codebase.**
- A sensor box needs Web Bluetooth: Chrome or Edge on Android or a computer. On iPhone it works through the Bluefy browser.
- The four non-Swedish dictionaries still have not been reviewed by a native speaker. Anything that reads wrong is a one-line fix — please report it under **Feedback**.
- Libell owns one ramp model at a time. If you own two different models, enter the one you want the app to plan with.
- The app deliberately refuses to run inside an iframe, so online "mobile viewer" sites show a blank page. That is the clickjacking guard, not a fault.
